# Google Ads - App Campaign Assets

Ready-to-use assets for Google App Campaigns promoting OpenIntelligence.

## Quick Start

1. Go to [Google Ads](https://ads.google.com)
2. Create new campaign → **App promotion** → **App installs**
3. Select iOS → Enter App Store ID
4. Copy/paste assets from files below

## Asset Files

| File               | Purpose                           |
| ------------------ | --------------------------------- |
| `headlines.txt`    | 5 headlines (30 char max each)    |
| `descriptions.txt` | 5 descriptions (90 char max each) |
| `image-specs.md`   | Image size requirements           |
| `video-specs.md`   | Video format requirements         |
| `keywords.txt`     | Suggested keyword themes          |
| `audiences.md`     | Target audience segments          |

## Budget Recommendations

| Daily Budget | Expected Results        |
| ------------ | ----------------------- |
| $20-50/day   | Testing phase (2 weeks) |
| $50-100/day  | Growth phase            |
| $100+/day    | Scale phase             |

**Tip**: Set daily budget at 50× your target CPI (cost per install).

## Campaign Settings Checklist

- [ ] Locations: United States (expand after testing)
- [ ] Language: English
- [ ] Bidding: Target CPI or Target CPA
- [ ] Conversion tracking: Firebase or SKAdNetwork
- [ ] Asset diversity: 4 headlines, 4 descriptions, 20 images, 20 videos

## Performance Benchmarks (iOS Productivity Apps)

| Metric | Good | Great |
| ------ | ---- | ----- |
| CPI    | $2-4 | < $2  |
| CTR    | 1-2% | > 2%  |
| CVR    | 2-4% | > 4%  |
