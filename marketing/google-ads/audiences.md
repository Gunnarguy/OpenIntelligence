## Audience Targeting Strategy

### Phase 1: Testing ($20-50/day)

```
Location: United States only
Audiences: Broad (let Google optimize)
Exclusions:
  - Age < 18
  - Low-income segments (for paid conversion)
```

### Phase 2: Optimization ($50-100/day)

```
Location: US, UK, Canada, Australia
Audiences:
  - Students & Academics (observation)
  - Knowledge Workers (targeting)
  - Tech Enthusiasts (observation)
```

### Phase 3: Scale ($100+/day)

```
Location: English-speaking markets
Audiences:
  - Lookalike from converters
  - Remarketing to website visitors
  - Top-performing segments only
```

---

## Exclusion Recommendations

Exclude these audiences to improve efficiency:

- **Age < 18**: Limited purchase intent
- **Low household income**: For paid tier campaigns only
- **Job seekers**: Typically not power users
- **Competitor employees** (if identifiable)
