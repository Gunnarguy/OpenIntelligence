# OpenIntelligence v4.1 User-Facing Changelog

Changes covered: commit `a4c70383ad60c22faab6a44135d289a15488396f` through `fc076b637d1766ebefeb819dd997ef5133d955a0`.

Version 4.1 is a quality-of-life and performance update to OpenIntelligence. This release refines the document processing queue, visual telemetry feedback, suggested questions quality, and external file picker behaviors.

Below is a summary of the improvements and fixes that make OpenIntelligence more responsive, reliable, and consistent to work with.

---

## What Users Will Notice First

*   **Live Reasoning Telemetry**: You can now watch the model's active thinking and processing states directly inside the chat metrics bar. 
*   **Smoother Visual Transitions**: The processing overlay transitions are now completely lag-free, resolving dynamic layout stutter when document uploads are started or completed.
*   **Cleaner Suggested Questions**: The suggested follow-up questions generated by the app are significantly cleaner, grammatically correct, and tightly focused on the specific contents of your library, filtering out OCR layout noise or generic phrases.
*   **Reliable File Picker Folders**: The document picker now remembers the exact directory you last imported files from (including folders within iCloud Drive or third-party storage providers), opening to that folder by default instead of defaulting to a random system directory.
*   **Cleaner Discarding**: Discarding or canceling an upload now completely nukes the document from the system, ensuring that partially ingested documents do not get stuck in a reload loop or reappear.

---

## Key Improvements

### 1. Telemetry and UI Responsiveness
- **Thinking State**: Added the `ThinkingStreamView` to the chat console's metrics panel so you can see live feedback while the local or cloud model organizes its thoughts.
- **GPU-Accelerated Popups**: The import progress dashboard transitions now render using GPU-accelerated opacity and scale operations, bypassing expensive layout calculations and compiler passes for a butter-smooth entrance animation.

### 2. Smart Folder Picker Memory
- **iCloud Drive Folder Persistence**: Replaced standard file paths with security-scoped file bookmarks. This allows the OS to securely verify your app's permission to return to the last folder you used, making the files app picker open to your preferred folder every time.
- **Auto-Cleanup**: Balanced security resource requests to release background sandboxing access immediately after you finish selecting files, preserving your device's memory and battery life.

### 3. Suggested Questions Polish
- **Diverse Suggestions**: The query planner uses a two-pass algorithm to ensure suggested questions represent diverse topics across different sections of your documents, instead of repeating the same ideas or falling back to empty fields.
- **Grammar Filters**: Standardized Part-of-Speech analysis to filter out adverb suffixes and layout junk, creating clean and natural follow-up topics.

### 4. Database Safety and Clean Discarding
- **Anti-Corruption Engine**: Rewrote vector database disk writes to use atomic file replacement. This prevents document database file corruption if an app reload occurs during ingestion.
- **Cascading Discard**: Discarding a document now triggers a clean cascading purge. It clears Spotlight indexes, SQLite databases, vector database chunks, and local source files, ensuring no orphaned file remnants are left behind.
- **Sync Merging**: Sync routines now leverage tombstone logs to guarantee that deleted or discarded documents do not get revived during bi-directional syncing.
