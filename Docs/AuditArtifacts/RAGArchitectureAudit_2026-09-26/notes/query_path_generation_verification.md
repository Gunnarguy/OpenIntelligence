> **Incident context (established earlier this session, cited from the brief, not re-derived here).** On 2026-09-25, on the macOS Debug build of 5.4 in Deep Think, "How much notice do I have to give before I move out?" over a 10-document library returned "1 lb. The proposed ~10-line fix is `scratchpad/proposed/SpecificationExtractor.proposed.diff` (expands "much/many" only with a fluid/container anchor word; compares exact unit tokens; orders keywords deterministically).

## 1. One query end to end, per quality mode (Standard, Deep Think, Maximum)

### Takeaway
Standard is one retrieval, one cross-encoder rerank, one packed prompt and one generation, wrapped in roughly a dozen heuristic stages that can re-order, re-weight, bypass or overwrite what the retrieval and the model produced. Deep Think and Maximum first try a pure-heuristic "precision lookup" that can answer with **zero generation calls**; only if it declines do they run the multi-session orchestrator, and even then a regex extractor can replace the orchestrator's synthesis at the end.

## 2. Context budgets and how many chunks reach the prompt

### Takeaway
On device, Standard budgets about **4.5K characters of evidence**, computed with a hard-coded 1.4 chars/token ratio, and it does not count its own ~2.2-2.6K-character system prompt; roughly 3-5 chunks of the ~30 MMR-selected (from ~90 reranked) reach the prompt. Deep Think sessions see 4,000 (session 1) or 2,200 characters (later sessions). Exact SDK token counts are used only by the routing planner.

### Cited Findings

## 4. Verification, source-only checking and answer labels

### Takeaway

## 6. Which decisions the language model makes and which heuristics make

### Takeaway
The model writes prose, plans a little, routes chunks inside the Deep Think chain and judges claims in the source-only check. Everything that decides *what kind* of question this is, *which* evidence wins, *whether* the model's answer stands, and *what label* the user sees is heuristic.

### Cited Findings
- Intent: heuristic (`classifyAnswerIntent`) [QES:335-663](OpenIntelligence/Services/Query/Enhancement/QueryEnhancementService.swift#L335) `[evidence_level: code_verified, confidence: exact]`.
- Routing between modes: the user; auto-escalation disabled for Apple FM [QueryRuntimeCoordinator.swift:211](OpenIntelligence/Services/RAG/Orchestration/QueryRuntimeCoordinator.swift#L211). Model-vs-PCC routing: `ModelExecutionPlanner` rules plus `FoundationModelRoutePolicy` [FRP:23-60](OpenIntelligence/Services/AIPlatform/AppleFoundationModels/FoundationModelRoutePolicy.swift#L23) `[evidence_level: code_verified, confidence: high]`.
- Model planner output actually consumed: `preferLiteralQuery` (gates rewrite) [RS:9914](OpenIntelligence/Services/RAG/Orchestration/RAGService.swift#L9914), `needsRetrieval` (Deep Think) [AO:3526](OpenIntelligence/Services/Agentic/AgenticOrchestrator.swift#L3526), `searchQueries` (Deep Think) [AO:1908-1915](OpenIntelligence/Services/Agentic/AgenticOrchestrator.swift#L1908), and a thinking-event title [RS:9530](OpenIntelligence/Services/RAG/Orchestration/RAGService.swift#L9530); `executionMode`, `subqueries`, `useStructuredEvidenceLookup` have no other consumer found `[evidence_level: grep_verified, confidence: medium]`.
- Query rewrite: heuristic ambiguity detection, then model [QueryRewriterService.swift:86, 249-264](OpenIntelligence/Services/Query/Rewriting/QueryRewriterService.swift#L86); expansion: heuristic synonyms/gazetteer [QES:719-906](OpenIntelligence/Services/Query/Enhancement/QueryEnhancementService.swift#L719) `[evidence_level: code_verified, confidence: exact]`.
- Retrieval/ranking: dense + BM25 + learned cross-encoder, then heuristic boosts, sniper, extractive re-sort (§1) `[evidence_level: code_verified, confidence: exact]`.
- Chunk reading order in Deep Think: model routing turn [AO:4638-4756](OpenIntelligence/Services/Agentic/AgenticOrchestrator.swift#L4638) `[evidence_level: code_verified, confidence: exact]`.
- Extraction/final answer: model generates; heuristic extractor may pre-empt (Deep Think/Maximum) or overwrite (all modes) [RS:8705, 8734, 9199, 14383, 15192](OpenIntelligence/Services/RAG/Orchestration/RAGService.swift#L14383) `[evidence_level: code_verified, confidence: exact]`.

- Abstention: gate confidence vs threshold, planner "insufficient evidence", Deep Think hard exit, Gate I, source-only abstain (preserved only for state/precision queries) [RS:17344-17362](OpenIntelligence/Services/RAG/Orchestration/RAGService.swift#L17344) `[evidence_level: code_verified, confidence: high]`.
- Labels and confidence: string parsing and fixed-coefficient formulas (calibration α/β/γ/δ presets) [ConfidenceCalibrationService.swift:28-70](OpenIntelligence/Services/RAG/Safety/ConfidenceCalibrationService.swift#L28) `[evidence_level: code_verified, confidence: exact]`.

### Inferences
- The architecture treats the language model as an untrusted text generator whose output heuristics may discard, while the heuristics themselves are unverified; the trust gradient is inverted relative to where errors were observed `[evidence_level: inferred, confidence: medium]`.

### Gaps
- None beyond §3.

## 7. Determinism: concrete causes in the query path

### Takeaway
There are at least ten independent sources of run-to-run variation: unseeded sampling in every model call, model-driven retrieval steps in Deep Think, a 180-second wall-clock loop, device thermal/battery state changing topK, device tier changing the Deep Think pipeline, history-dependent query caches, and several sorts without a total order at top-K cuts.

### Cited Findings
- **Unseeded sampling** everywhere by default (`seed = nil`, `.random(top: 40)`) [LLMModel.swift:137-144](OpenIntelligence/Core/Models/LLMModel.swift#L137), [LLM:787-801](OpenIntelligence/Services/LLM/LLMService.swift#L787); agentic helpers build configs without seeds (temperature 0.5 default, 0.7 fresh sessions) [AO:8904-8925, 8938-8970](OpenIntelligence/Services/Agentic/AgenticOrchestrator.swift#L8938) `[evidence_level: code_verified, confidence: exact]`. ## 10. Structural problems (not one-off bugs)

### Takeaway
The incident is the intersection of at least eleven separate decisions, of which the proposed fix changes two. The same shapes recur across the codebase: substring word lists deciding semantics, a single heuristic intent flag gating a dozen behaviours, heuristics that overwrite model output without an answer-type check, thresholds calibrated on one score scale and applied to another, and labels that default to success.

### Cited Findings
- **Incident chain vs the proposed fix** (each link code_verified at the cited line): (1) "how much" → `.lookup` [QES:608](OpenIntelligence/Services/Query/Enhancement/QueryEnhancementService.swift#L608); (2) precision lookup pre-empts the orchestrator [RS:8904](OpenIntelligence/Services/RAG/Orchestration/RAGService.swift#L8904); (3) sniper's substring co-occurrence over all chunks — for this question the concepts are "notice", "give", "move", "out" (after stopwords), and `contains` matches them inside "remove", "given", "about", "without" [RS:2535-2540](OpenIntelligence/Services/RAG/Orchestration/RAGService.swift#L2535), [ESP:318-325](OpenIntelligence/Services/RAG/Tuning/EvidenceScoringPolicyService.swift#L318); (4) much→volume expansion [SE:1482](OpenIntelligence/Services/Query/Analysis/SpecificationExtractor.swift#L1482) **(fixed by proposal)**; (5) " l" unit substring [SE:587](OpenIntelligence/Services/Query/Analysis/SpecificationExtractor.swift#L587) **(fixed by proposal)**; (6) same-category competitors never count as ambiguous [SE:300-305](OpenIntelligence/Services/Query/Analysis/SpecificationExtractor.swift#L300); (7) an additive bonus score treated as confidence against 0.82 [ESP:83](OpenIntelligence/Services/RAG/Tuning/EvidenceScoringPolicyService.swift#L83); (8) span returned as the whole answer with no answer-type check [RS:17962-18012](OpenIntelligence/Services/RAG/Orchestration/RAGService.swift#L17962); (9) source-only declines locked answers [RS:17293](OpenIntelligence/Services/RAG/Orchestration/RAGService.swift#L17293); (10) hard-coded ≥0.90 confidence [RS:8608](OpenIntelligence/Services/RAG/Orchestration/RAGService.swift#L8608); (11) default-Verified label [MessageBubbleV2.swift:688-702](OpenIntelligence/Features/Chat/Conversation/MessageBubbleV2.swift#L688) `[evidence_level: code_verified, confidence: exact for each link; that all eleven fired in the incident is inferred from the brief, confidence: high]`.
