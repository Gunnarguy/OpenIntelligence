# Audio edition of the study guide

Plain text written to be read aloud by a text-to-speech app such as ElevenLabs Reader. No tables,
no file paths or line numbers, identifiers spoken as words, abbreviations spelled out, and a pause
cue before every quiz answer. Generated from the same source as `Docs/STUDY_GUIDE.md`; that file
is the one with citations, and it wins where the two differ.

- `STUDY_GUIDE_AUDIO_FULL.txt` is everything in one paste.
- `00_` to `18_` are the same text split by module, so a single module can be listened to alone.

Order: 00, then 01 to 16, then 18. There is no 17; module numbering follows the word bank, which
runs 00 to 16.
