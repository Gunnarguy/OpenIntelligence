APP OVERVIEW:
OpenIntelligence is an on-device RAG (Retrieval-Augmented Generation) engine. Users import documents (PDF, Word, Excel, PowerPoint, Markdown, CSV, RTF, TXT, images), the app indexes them locally using a 29-step retrieval pipeline, and then answers natural language questions with cited sources. All AI processing uses Apple Foundation Models on-device. 102 services across 11 categories. Zero network dependency for core functionality.

KEY FEATURES:
- 29-step retrieval pipeline: semantic chunking, hybrid search (BM25 + neural embeddings), cross-encoder reranking, MMR diversification, parent document retrieval, graph context packing, lost-in-middle mitigation
- 7 anti-hallucination verification gates (A-G): retrieval confidence, evidence coverage, numeric sanity, contradiction detection, semantic grounding, quote faithfulness, generation quality
- Evidence-First mode: when query-document overlap is low, AI states available evidence instead of generating unsupported answers
- 3 quality modes: Standard (fast), Deep Think (4-8 reasoning sessions), Maximum (8-50 sessions, research-grade)
- 8 agentic tools: search, compare, summarize, timeline, extract, define, calculate, analyze
- AI Hub transforms: Key Facts, Step-by-Step, Plain English, Gap Analysis, Illustrate — all grounded in source documents
- Multi-column OCR at 360 DPI with font cipher detection (forces full OCR when text layer is garbled)
- Motherboard HUD: real-time Apple Silicon telemetry overlay
- Device-optimized: 3-tier Metal GPU shaders adapt to chip family (A15 through M4)
- Rich markdown rendering for all responses
