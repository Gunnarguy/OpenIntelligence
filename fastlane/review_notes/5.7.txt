New in 5.7: JSON and JSON Lines files import as records, and very large text files import a piece at a time, so an interrupted import continues. The app accepts files through "Open in" and has a Paste button; iOS may show its own paste prompt. Shortcuts actions now return their results, and new actions add to a library, create or switch a library and open a library or a document. "Save a Web Page" downloads the page at the address the person gives; the request goes to that site only. New permission: notifications, requested only when the person turns on the switch in Settings; a notification never contains the question or a file name. The plans screen has a Redeem a Code button that opens Apple's offer code sheet. New capability: Background GPU Access, used with BGContinuedProcessingTask so an import the person started can continue after they leave the app. MetricKit reports stay on the device and are sent nowhere. No new purchases.
