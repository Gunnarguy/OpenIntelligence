Demo account: Not required.

Reviewer walkthrough:
1. Launch OpenIntelligence — the app works fully offline with on-device processing.
2. Go to Settings > AI Providers to optionally add API keys (OpenAI, Anthropic, etc.).
3. Create a Knowledge Container and import a document from Files.
4. Ask a question about the imported document to test RAG retrieval.
5. Toggle between on-device and cloud models in Settings to verify provider switching.

Note: Apple Intelligence features require a device with Apple Intelligence support (iPhone 16 or later). The app falls back gracefully on unsupported devices.
