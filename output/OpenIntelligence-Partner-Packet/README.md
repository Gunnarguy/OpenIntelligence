# OpenIntelligence Partner Packet

This folder exists to make buyer conversations easy.

Do not treat it like a giant reading list.

Use it like an operator packet.

## If You Only Use Five Things

If you want the minimum viable selling stack, use only these:

1. `FOUNDER_SALES_RUNBOOK.md`
2. `CURRENT_COMMITMENTS.md`
3. `DATA_BOUNDARIES.md`
4. `../OpenIntelligence-SDK-Package/build/OpenIntelligenceEngine-Buyer-Packet.zip`
5. `../OpenIntelligence-SDK-Package/SampleApp/EngineEvaluationHost.xcodeproj`

Everything else is secondary.

## Start-To-Finish Process

### 1. Someone messages you

Open:

- `FOUNDER_SALES_RUNBOOK.md`

Use it for:

- the first reply
- the qualification questions
- the first-call talk track
- the follow-up flow

### 2. Before the call

Open:

- `CURRENT_COMMITMENTS.md`
- `DATA_BOUNDARIES.md`
- `../OpenIntelligence-SDK-Package/SampleApp/EngineEvaluationHost.xcodeproj`

Use them for:

- staying truthful
- answering privacy / data-handling questions
- running the live demo

### 3. During the call

Show:

- the demo app
- the buyer packet exists
- the engine is real

Do not dump every document on them.

### 4. After a good first call

Send:

- `../OpenIntelligence-SDK-Package/build/OpenIntelligenceEngine-Buyer-Packet.zip`

If they want supporting proof, then add:

- `CURRENT_COMMITMENTS.md`
- `DATA_BOUNDARIES.md`
- `../../EngineSale/ENGINE_INVENTORY.md`

### 5. If they get technical

Open these only when needed:

- `../OpenIntelligence-SDK-Package/API.md`
- `../../OpenIntelligence/SDK/OpenIntelligenceEngine.swift`
- `../../Docs/STORAGE_AND_PIPELINE_TRACE.md`
- `../OpenIntelligence-SDK-Package/Internal/BUILD_NOTES.md`

Use them for:

- how another app would use the engine
- the real code entry points
- how the pipeline works
- what is still blocked in packaging

### 6. If they get serious

Open:

- `EVALUATION_PROCESS.md`
- `PRICING.md`
- `DESIGN_PARTNER_OFFER.md`

Use them for:

- when to use NDA and evaluation terms
- what to charge first
- how to frame the pilot or partner motion

## What This Packet Is For

Use this packet for:

- early buyer qualification
- founder-led demo conversations
- technical evaluation framing
- design-partner or pilot setup
- codebase-head-start discussions

Do not use this packet to pretend the repo is already a polished self-serve enterprise SDK.
