# EngineSale

This folder exists to describe the engine honestly as something that could be sold, licensed, evaluated, or handed off without overselling it.

Use the files in this order:

- use `ENGINE_PITCH.md` for outreach, listing copy, or first-pass buyer framing
- use `ENGINE_INVENTORY.md` for technical buyers and diligence conversations
- use `KNOWN_LIMITATIONS.md` for honesty and risk disclosure
- use `HANDOFF_CHECKLIST.md` before any sale, license, diligence, or transfer discussion
- use `CLAIMS_GUARDRAILS.md` before posting publicly or sending marketing copy

Practical rule:

- this folder is for describing a substantial engine prototype and codebase asset
- it is not for pretending the repo is already a finished enterprise SDK
