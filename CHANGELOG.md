- **[Infrastructure]** **Documents no longer disappear when an import finishes while a sync pass is running.** This was the actual cause of vanishing documents, including the sample set, and it is not an iCloud fault — it reproduces on one device. `synchronizeConfiguredLibraries` snapshots `documents_metadata.json` at the start of a pass, then merges containers, resolves aliases, and awaits iCloud downloads in `ensureSourcedDocumentsAvailableLocally` before writing its computed set back over that same file.
