### Added
- **[General]** **An evaluation pack whose ground truth this project did not write, and whose corpus contains documents that are not the answer.** `Benchmarks/ResearchFixtures/qasper_external_v1/` holds 83 cases over 40 papers drawn from QASPER (Dasigi et al., NAACL 2021, CC BY 4.0), built by `scripts/build_external_fixtures.py`. The questions were written by readers who had seen only a title and abstract, and answered by separate annotators against the full text; a case is kept only where at least two annotators agreed, and the count rides along in `annotator_agreement`. Six abstention controls come from questions a majority of annotators judged genuinely unanswerable, replacing two the project had invented for itself. The load-bearing change is not the source of the data, though: the manifest declares a top-level `pool` that `run_quality_matrix.py` ingests for **every** case, so each question is asked against 39 distractor papers. Until now the runner created a fresh store per case and ingested only that case's `input_files` (`run_quality_matrix.py:391`, `:720`), which meant every case was scored against an index holding nothing but its own expected file. The 2026-08-11 reports show the consequence directly: the vector stage saw between two and five candidate chunks per case and all of them were correct, so `R@5` and `MRR@10` read 1.000 as arithmetic rather than as a pipeline result. A fixture with no distractors can register a regression and can never demonstrate an improvement, which is why the embedder comparison had nothing to win on. `fixtures.lock.json` pins the dataset revision, the selected papers and questions, and a SHA-256 over the corpus; `--check` verifies it offline, and two independent rebuilds produce a byte-identical tree. `scripts/build_eval_dataset.py` now renders every known pack, so `Benchmarks/rag_eval_qasper_v1.jsonl` reaches the in-app `RAGEvalCase` framework the same way the synthetic set does.

- **[Retrieval]** **The per-stage retrieval metrics are wired into the harness, so the repository can measure its own retrieval for the first time.** Commit `cb82471` landed the measurement instrument and said plainly that it was not connected.
